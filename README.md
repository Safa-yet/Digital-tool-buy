#  Digital Tool

**Digital Tool** is a modern subscription-based web application where users can explore and purchase various AI-powered tools. It features a clean, responsive, and user-friendly interface designed for a smooth browsing and buying experience.

---

## 🛠️ Technologies Used

* 🌐 HTML5
* 🎨 CSS3
* 💨 Tailwind CSS
* 🌼 DaisyUI
* ⚛️ React.js
* 🧠 JavaScript (ES6+)
* 🔔 React Toastify
* 🎯 Lucide Icons

---

## ✨ Features

* ⚡ Browse and explore multiple modern AI tools with a clean UI
* 🛒 Add and manage selected tools with interactive feedback (toast notifications)
* 🎨 Fully responsive and modern design with smooth hover and UI effects
